# Garuda Cleaning Services — Tirupati

Premium deep-cleaning, institutional sanitation, and facility management web application built for **Garuda Cleaning Services** (Tirupati, Andhra Pradesh).

## 🚀 Features

- **7 Dedicated Pages**:
  - `Home (/)`: Hero conversion engine, trust indicators, popular capabilities, transformation slider, and honest review badge.
  - `Commercial & Corporate (/commercial)`: Specialized B2B solutions for Hotels, Offices, Healthcare, Retail, and Education with GST invoicing and dedicated supervisor support.
  - `Services Directory (/services)`: 22 comprehensive residential and commercial cleaning services with live category filtering.
  - `About Us (/about)`: Brand mission, Tirumala vahana heritage, and 4 quality standards.
  - `Transformations & Process (/transformations)`: Interactive before/after drag comparison sliders and 5-stage cleaning workflow.
  - `FAQ (/faq)`: Structured homeowner & commercial FAQ accordion with schema markup.
  - `Contact & Booking (/contact)`: Instant WhatsApp booking generator, direct call desk, business hours, and Google Maps embed.
- **Color Palette**: Fresh Botanical Emerald (`#059669`), Soft Mint (`#ECFDF5`), and Porcelain White (`#FFFFFF`, `#F8FAFC`).
- **Typography**: Google Font **Plus Jakarta Sans** and **Inter**.
- **Conversion-First**: Direct deep links to WhatsApp and click-to-call (`+91 77995 52084`).

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Framer Motion**
- **React Router DOM v7**

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
